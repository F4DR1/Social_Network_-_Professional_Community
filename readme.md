# Социальная сеть для профессионального сообщества

Дипломный проект. Платформа для общения и обмена опытом специалистов. В разработке.


## Стек

### Frontend
- PHP (MVC-архитектура, без фреймворка)
- HTML
- CSS
- JS

### Backend
- PHP (MVC-архитектура, без фреймворка)
    - league/commonmark ^2.4
    - predis/predis ^3.4
    - vlucas/phpdotenv ^5.6
- MySQL

### WebSocket
- python 3.7+
    - aiohttp 3.7
    - redis 4.2
    - websockets 9.0

## Запуск проекта
1. Склонировать репозиторий;
2. Настроить веб-сервер (например, `OpenServer` или `XAMPP`) с поддержкой PHP и MySQL;
3. Импортировать дамп БД из папки `database` (временно отсутствует) в базу данных MySQL;
4. Установить все нужные зависимости (для WebSocket это `requirements.txt` в папке `ws`, для API - `composer.json` в `api`);
5. Открыть сайт в браузере.

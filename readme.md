## Запуск проекта
1. Склонировать репозиторий;
2. Настроить веб-сервер (например, `OpenServer` или `XAMPP`) с поддержкой PHP и MySQL;
3. Импортировать дамп БД из папки `database` (временно отсутствует) в базу данных MySQL;
4. Установить все нужные зависимости (для WebSocket это `requirements.txt` в папке `ws`, для API - `composer.json` в `api`);
5. Установить Redis (если ещё нет);
6. Настроить все данные для подключений (в `ws` настроить `.env`; в `api` настроить `.env`; в `public` настроить `socket_manager.js` - переменную `wsUrl` в `connect()`);
7. Запустить WebSocket;
8. Открыть сайт в браузере.

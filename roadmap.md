# По проекту
Чистый php с нуля, без библиотек и CMS.

## Что уже сделал и что сделать ещё
### Что уже сделано в соцсети:
* Регистрация/авторизация (путём токенов сессии, упрощённая версия jwt);
* Профили пользователей (подписка/отписка на пользователей, блокировка пользователя и изменение списков отношений с пользователем; оставлять посты (описание дальше); изменение списка навыков: редактирование своих навыков, подтверждение навыков других пользователей);
* Профили групп (подписка/отписка на группу, просмотр всех пользователей в группе, оставлять посты (описание дальше), настройки: изменение название группы и его username - короткой ссылки);
* Посты (можно оставлять посты в профиле или группе; у постов есть типы контента - обычный (просто текст поста), статья (фото с кнопкой открытия статьи), файлы);
* Типы контентов: медиа, статьи;
* Список контактов (посмотреть кто подписан на пользователя и на кого подписан он, а также кто есть в контактах (подписаны друг на друга) уже);
* Список групп (посмотреть на какие группы подписан, посмотреть свои группы, создать новую группу (нужно только название новой группы));
* Заглушки под мессенджер, ленту и поиск. Также на настройки аккаунта и профиля пользователя.

### Что будет ещё:
* Больше типов контента: опросы, вакансии (может что-то ещё?);
* OAuth (пока что только через GitHub и Google);
* Поиск (очень глубокий - по всем тегам, типам контента и так далее);
* Кейсы задач в профиле (над чем работал, проекты);
* События (их может организовывать группа или пользователь);
* Мессенджер (это уже пошёл ws дальше);
* Уведомления;
* Статус "В сети".

## Описание групп
Что такое группа? По сути это сообщество (как во ВКонтакте), только они будут направлены в определённую среду (например, если это сообщество по языку программирования Java, то оно будет иметь определённые теги для понимания что это за сообщество), а также свою беседу (как чаты во ВКонтакте, только по всему сообществу для всех подписчиков (и только для них)). Возможно ещё какой-то функционал по группам будет в дальнейшем.

## Посты
Пользователь может публиковать посты на своей странице и в группе. Посты видят все пользователи, но редактировать / удалять их может только владелец профиля/администратор группы. Пользователь может добавлять к посту различные файлы со своего (пока что) устройства.

## Контент
### Статьи
Статьи призваны заменить посты в случаях, когда объём текста большой, а также позволяет форматировать текст благодаря формату markdown, в котором он создаётся. Пользователь может создать свою статью и сохранить (временно отключено) / опубликовать статью. Любой пользователь может прочитать статью, и она будет показываться в формате html (markdown конвертируется в html и выводится пользователю).

### Файлы
Сейчас поддерживаются только изображения, но в будущем вариация будет расширена.
